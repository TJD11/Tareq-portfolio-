# Tareq | Web Developer Portfolio

A modern, responsive personal portfolio website built to showcase my front-end development skills and projects.

## 🚀 Features
- Responsive design (mobile, tablet, desktop)
- Smooth scrolling and animations
- Portfolio filtering system
- Functional contact form using **EmailJS** (sends messages directly to my email)

## 🛠️ Technologies Used
- HTML5
- CSS3 (Flexbox & Grid)
- Vanilla JavaScript
- EmailJS (for contact form)
- Font Awesome (icons)
